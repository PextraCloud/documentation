# View Federations
1. Select the datacenter in the resource tree and view the page on the right. Click on the **Multi-Cluster Federations** tab in the right pane.
   ![The datacenter detail page with the Multi-Cluster Federations tab selected](./images/federations-tab.png)

The **Multi-Cluster Federations** tab shows all federations associated with the selected datacenter. Fields displayed include the name, description, remote cluster ID, enable status, endpoint, and sync status. For more information on sync status, refer to the [Connectivity](./connectivity.md) section.

To create a multi-cluster federation, refer to the [Create Federation](./create-federation.md) section.
